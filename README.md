# Python Banking System

A simple Python banking system that I built while learning Object-Oriented Programming (OOP).

This project is part of **Module 3 – Object-Oriented Python**. I made it to understand how classes and OOP concepts are actually used in a small practical application instead of only studying them as theory.

## What I learned

While working on this project, I practiced:

- Classes and objects
- Constructors
- Methods
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Basic clean-code practices
- Designing classes for a real-world type problem

## What the Banking System can do

The application is designed around common banking operations:

- Create a bank account
- Deposit money
- Withdraw money
- Check account balance
- View transaction history
- Handle invalid operations

## OOP Concepts Used

### 1. Classes and Objects

Classes are used to represent banking entities, and objects are created from those classes.

### 2. Encapsulation

Account-related data and operations are kept together inside classes.

### 3. Inheritance

Related account types can share common functionality through inheritance.

### 4. Polymorphism

Different account types can provide their own implementation of common methods.

### 5. Abstraction

The important operations are exposed to the user while unnecessary internal details are kept inside the classes.
